# TarifWerk Produkt-, Partner- & Vermarktungs-Hub Prompt

## 28. PRODUKT-, PARTNER- & VERMARKTUNGS-HUB

Baue im TarifWerk-Backoffice einen zentralen Bereich:

**„Produkte & Partner“**

Dieser Bereich soll die zentrale interne Wissens- und Vertriebsdatenbank von TarifWerk werden.

ZIEL:

Jeder Mitarbeiter soll sofort erkennen können:

- Welche Produkte bietet TarifWerk an?
- In welchem Geschäftsbereich gehört das Produkt?
- Über welchen Anbieter / Kooperationspartner läuft es?
- Über welchen Distributor / Maklerpool / Vermittlungspartner läuft es?
- Wo und wie dürfen wir es vermarkten?
- Für welche Zielgruppe ist es geeignet?
- Welche Provision gilt?
- Welche Dokumente werden benötigt?
- Wer ist interner Ansprechpartner?
- Wie läuft der Abschluss?
- Wo wird der Auftrag eingereicht?
- Welche Besonderheiten gibt es?
- Welche aktuellen Aktionen / Incentives existieren?

Das System soll dafür sorgen, dass kein Mitarbeiter mehr Informationen über WhatsApp, alte PDFs, E-Mails oder verschiedene Portale zusammensuchen muss.

Alles Relevante gehört zentral ins TarifWerk-Backoffice.

2. Bedarf feststellen
3. notwendige Daten aufnehmen
4. Unterlagen prüfen
5. Produkt auswählen
6. Antrag einreichen
7. Auftrag dokumentieren
8. Status verfolgen
9. Kunden informieren
10. Provision überwachen

Je Produkt individuell konfigurierbar.
