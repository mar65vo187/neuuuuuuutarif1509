## 2. OWNER-INTERNER 15-%-BUDGETTOPF

Von jeder eingelesenen Anbieterprovision wird intern automatisch eine Owner-Rücklage von 15 % berechnet.

Beispiel:

Anbieterprovision:
1.000 €

Owner-interner Benefit-/Investment-Pool:
150 €

verbleibende interne Berechnungsbasis:
850 €

Dieser 15-%-Topf ist ausschließlich für meinen Owner-Account sichtbar.

NORMALE MITARBEITER:
dürfen diesen internen Kostenblock nicht sehen,
dürfen keine Owner-Kalkulation sehen,
dürfen keine Unternehmensmarge sehen,
dürfen keine internen Rücklagenbudgets sehen.

ABER:

Vertraglich zugesagte Vergütung darf durch diese interne Darstellung niemals heimlich verändert oder nachträglich gekürzt werden.

Das System muss sauber zwischen unterscheiden:

Provider-Bruttoprovision
interner Unternehmensplanung
Mitarbeiter-Vergütungsbasis
Mitarbeiteranspruch
Stornoreserve
Benefit-/Incentivebudget
Unternehmensanteil
tatsächlicher Auszahlung

Nur mein Owner-Account erhält die vollständige Waterfall-Ansicht.
